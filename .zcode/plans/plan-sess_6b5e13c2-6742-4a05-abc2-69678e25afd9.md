# 将「AI业务技能」11 个技能复制进 ZCode 技能库

## 方案

把 `/Users/baoyanhu/西贝项目/AI业务技能/` 下的 11 个技能目录复制到 ZCode **用户级技能库** `~/.zcode/skills/`(对所有项目生效,含 kefang)。

## 执行步骤

1. **创建目录** `~/.zcode/skills/`(若不存在)
2. **复制 11 个技能目录**(SKILL.md + templates/references/脚本等附属资源一并带走):
   ftp-storage、init-project、mdc-sdk、mp-api-code-style、mp-code-style、rms-sdk、sendmsg-sdk、session-snapshot、wechat-sdk、welife-sdk、xibei-api-client
   - 不复制根目录的 AGENTS.md(它是全局工作流文档,不是技能;kefang 项目里已有同内容的 docs/AGENTS_GLOBAL.md)
3. **验证**:
   - 逐个确认 `~/.zcode/skills/<name>/SKILL.md` 存在且 frontmatter 的 name 与目录名一致
   - 确认 11 个技能名与现有插件技能(browser-use、document-skills 等)无重名冲突(已预查,无冲突)
4. **提醒重启**:技能在会话启动时扫描,新技能需重启 ZCode 会话后出现在「设置 → 技能」和可用技能列表

## 说明

- 复制(非软链)是按你的要求;以后源目录技能更新后,重跑同一条 cp 命令即可同步
- mp-api-code-style 里的 SKILL-1.md/AGENTS-1.md 旧版残留文件会原样带走(扫描器不读它们,无害)
- 生效后触发词示例:说「接入 MDC」→ mdc-sdk;「小程序接口规范」→ mp-api-code-style;「初始化项目」→ init-project
